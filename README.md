# Cloudflare × Alchemy × Effect

Slides built with [reveal.js](https://revealjs.com) 6.0.2, vendored in `dist/` (prebuilt, no npm needed).

## Run

Open `index.html` in a browser. That's it.

If you load slides from external files (e.g. `data-markdown="slides.md"`), serve the folder instead:

```bash
python3 -m http.server 8000
```

## Presenting

- `S` speaker view (notes + timer)
- `F` fullscreen, `Esc` / `O` overview, `B` blackout
- `Alt`+click to zoom
- PDF: open `index.html?print-pdf` in Chrome, then Print → Save as PDF
